在回答什么

东栅偏原住民生活与观光，西栅偏度假与夜游；门票、业态、空间组织都不同。想用数据回答三件事：

  1. 两栅游客的情感倾向是否有显著差异；
  2. 差异集中在哪些体验维度（餐饮、住宿、拥挤、夜景、服务、价格……）；
  3. 差异是否随季节与年份变化。

数据 内容 用途

复现步骤

代码在 code/ 下，按序号依次运行；所有路径、词典与 Key 集中在 code/config.py。

  1. 环境自检：python code/00_check_env.py（Python 3.9+）。
  2. 采集点评：浏览器里复制 cURL 存成本地文件，运行 python code/01_collect_ctrip.py，脚本按此翻页，支持断点续采。
  3. 采集 POI：python code/02_collect_amap_poi.py。
  4. 清洗：python code/03_clean.py，去重、去广告、剔除重复景区简介。
  5. 地点归属与分句：python code/04_segment.py，输出东栅／西栅／双栅标记。
  6. 规则分类：python code/05_rule_classify.py，21 类主题词作为可解释基线。
  7. 生成标注表：python code/06_make_label_sheet.py，分层抽样。
  8. 训练分类器：python code/07_train_classifier.py，训练后全量预测。
  9. 情感分析：python code/08_sentiment.py，无 Key 时自动走本地词典后端。
  10. 构建特征：python code/09_build_features.py，输出随机森林特征矩阵。
  11. 组间检验：python code/10_compare_stats.py，卡方 / Mann-Whitney U / FDR 校正。
  12. 建模与解释：python code/11_rf_shap.py，置换重要性、SHAP 与偏依赖。
  13. 出图：python code/12_timeseries_plots.py，时间序列与 300 dpi 图件。

方法上的取舍

  • 规则分类与模型分类并行：前者可解释、可复查，后者接住长尾表达。
  • 组间检验一律做多重比较校正，避免「21 个主题里挑三个显著」。
  • 重要性同时给置换重要性与 SHAP，避免单指标误判。

About the project

An undergraduate innovation and entrepreneurship programme, now concluded. There is no plan to publish; code and reproduction steps are public, data are available on request.

Question

Dongzha is closer to everyday life and sightseeing, Xizha to resort and night tourism; tickets, businesses and spatial layout differ. Three questions:

  1. Is the sentiment of visitors significantly different between the two gates?
  2. If so, along which dimensions — food, lodging, crowding, night scenes, service, price?
  3. Does the gap vary by season and year?

Data

Dataset Content Use
Visitor reviews text, rating, date, gate primary data
Amap POI nearby businesses and facilities business structure
Human-labelled sample stratified sample, manually tagged topics training and validation
Operating data annual figures 2016–2024 context

Reviews and POI are not distributed with the repository. Sample sheets are available by email.

Steps

Thirteen runnable scripts, in order: environment check, review collection (cURL-based, resumable), POI collection, cleaning, gate attribution and sentence splitting, rule-based 21-topic labelling, label sheet generation, classifier training, sentiment analysis with a local fallback backend, feature building, group tests (chi-square / Mann-Whitney U / FDR), random forest with permutation importance and SHAP, then time-series plots at 300 dpi.
