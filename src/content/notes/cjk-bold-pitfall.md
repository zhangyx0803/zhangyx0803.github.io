---

在 README 里写：

```markdown
- 🎓 **Education:** GIS.
  <br>**教育背景：**地理信息科学专业。
```

显示出来是 `**教育背景：**地理信息科学专业。`——星号原样出现，只有英文那行正常。

## 原因

CommonMark 判断一段 `**` 能不能闭合，看它左边和右边各是什么字符（flanking rules）。
闭合要求「右侧不跟空白」，并且「不是紧跟标点」；如果左边是标点，还要看右边是不是空白或标点。

`**教育背景：**地理` 里，闭合的 `**` 左边是中文冒号 `：`（标点），右边是汉字（字母类）。
于是它**左边是标点、右边是字母**——两条规则都不满足，闭合失败。

## 三种改法

```markdown
**教育背景**：地理信息科学专业。     ← 冒号移到外面，首选
**教育背景:**地理信息科学专业。      ← 用半角冒号但后面加空格
<b>教育背景：</b>地理信息科学专业。    ← 直接用 HTML 标签
```

第一种最稳：`**` 左边是汉字、右边是标点，闭合成成立。

## 怎么快速验证

GitHub 用的解析器是 cmark-gfm，本地可以直接调用它，比反复推送到线上看快得多：

```python
import cmarkgfm
print(cmarkgfm.github_flavored_markdown_to_html("**标签：**正文"))
```

输出里如果看到 `<strong>` 就说明成了；如果看到字面的 `**`，就是分隔符规则没过。

> 类似的还有：中文引号紧贴 `*斜体*`、中文括号包住链接文字。
> 判断标准始终是那一条——**看紧邻的字符是字母还是标点**。
